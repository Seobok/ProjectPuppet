# 튜토리얼 시연

## 실행

- `Assets/_Project/Scenes/Tutorial.unity`를 열고 Play합니다. 빌드 설정의 첫 번째 씬입니다.
- 이동·점프 → 기본 공격 → Mushroom 회피 → 인간형 적 패링 → 체크포인트 → 기사 보스 순서입니다.
- 안내를 완료하지 않아도 다음 구간으로 이동할 수 있습니다. 키 표시는 현재 입력 바인딩과 마지막 사용 장치에 맞춰 바뀝니다.

## 재도전 규칙

- 체크포인트 전 사망: 입구에서 플레이어와 일반 적을 새로 생성합니다.
- 보스 앞 체크포인트 첫 활성화: 체력을 회복하고 통과한 일반 적을 비활성화합니다. 반복 활성화로 체력을 회복할 수 없습니다.
- 활성화 후 사망: 보스 앞에서 복귀합니다. 일반 적은 비활성화 상태를 유지하고, 보스는 다음 입장 시 최대 체력으로 시작합니다.
- 학습 완료 표시는 재도전 중 유지합니다. 클리어 또는 사망 메뉴의 '처음부터 다시 시작'은 체크포인트·학습 상태를 모두 초기화합니다.
- 상태는 실행 중 메모리에만 보관합니다. Play를 종료하면 초기화되며 파일 저장은 없습니다.

## 구성과 조정

- `RunFlow/RetryController`: 복귀 위치, 사망 메뉴 지연, 일반 적 구간 연결.
- `BossCheckpoint`: 체크포인트 ID·순서·복귀 Transform. 복귀 위치는 문 바깥 안전 지대에 둡니다.
- `BossEncounter`: 입장 트리거, 출입문, 비활성 보스 인스턴스 연결.
- `TutorialZone`: 학습 안내 구간. 학습 판정은 `TutorialDirector`가 담당합니다.
- `TutorialHUD`: 플레이어·보스 체력, 안내, 체크포인트 알림, 사망·클리어 메뉴. UI 입력은 플레이어 입력과 분리되어 사망 후에도 동작합니다.
- `TutorialCamera`: 플레이어 추적과 좌우 맵 경계.
- 캐릭터 체력·전투 수치는 기존 프리팹 설정을 사용합니다.

현재 한글 SDF 폰트에는 안내에 필요한 글자를 정적으로 구웠습니다. 새로운 한글 문구를 추가하면 폰트의 글리프도 함께 확인해야 합니다.

## 검증

튜토리얼 씬의 새 Play 세션에서 다음 명령을 실행합니다.

```powershell
unity command run_script --file Tools/Verification/VerifyTutorialFlow.cs --format json
```

입력 장치별 안내, 학습 완료, 실제 씬 재로드, 체크포인트 회복·복귀, 보스 초기화, UI raycast·submit, 클리어 후 초기화 및 EventSystem 중복 방지를 확인합니다. 전투 판정 자체는 기존 Player/Mushroom/KnightBoss 검증 스크립트로 별도 확인합니다.
